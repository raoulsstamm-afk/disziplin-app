# Disziplin (Arbeitstitel)

Deutsche App gegen Aufschieben: drei Aufgaben am Tag mit Foto-Beweis und ein Lock-in-Timer (25, 50, 90 Minuten). Sanfte Serie mit Joker, Level, Nacht-Stil. Expo SDK 57, Expo Router, TypeScript. Alles bleibt lokal auf dem Handy, auch die Fotos.

- Starten: `npm install`, dann `npx expo start`
- Prüfen: `npx tsc --noEmit` und `npx expo install --check`
- Web-Fotos aller Bildschirme: `npm run web-export && npm run screenshots` (Bilder in `docs/screenshots/`)
